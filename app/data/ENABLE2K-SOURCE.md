The original source notice is preserved verbatim in `README-enable2k.txt`. It states that the ENABLE master word list is in the Public Domain, credits Alan Beale and other ENABLE contributors, and asks game designers to mention the source and credit the originators. This application uses the list only as its clearly marked, nonofficial **Community Dictionary (ENABLE2K)**; it does not represent current tournament word-list rules.
